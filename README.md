# SponsorPerks
Косметические перки для VIP-группы на Minecraft-сервере (Paper). GUI-меню выбора свечения и питомцев для спонсоров.

## Возможности
- GUI-меню (инвентари) выбора косметики
- Свечение (цвета), питомцы-компаньоны
- Привязка к группе прав (LuckPerms / Vault)

## Сборка
`mvn clean package` (JDK 21).

## Стек
`Java 21` · `Paper API` · `Bukkit GUI` · `Maven`
